# PRISM

Professional Real-time Intelligent Smart Presence Management

## Hardware
- ESP32 Dev Module
- R307S Fingerprint Sensor
- SSD1306 OLED Display
- DS3231 RTC
- Micro SD Card Module
- Active Buzzer

## Features
- Fingerprint Authentication
- OLED User Interface
- SD Card Attendance Logging
- RTC Timestamping
- Wi-Fi Synchronization
- Web Dashboard
- Offline Data Backup
